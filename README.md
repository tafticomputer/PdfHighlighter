# هایلایت PDF (اندروید ۵.۱ به بالا)

برنامه‌ای برای باز کردن PDF، هایلایت کردن مطلب و ذخیره‌ی خودکار هایلایت‌ها.

## امکانات
- باز کردن PDF از حافظه یا از هر برنامه‌ای که «باز کردن با…» دارد
- **بستن فایل** با دکمه‌ی ✕ بالای صفحه (هایلایت‌ها ذخیره می‌مانند)
- **زوم با دو انگشت** (تا ۵ برابر) و جابه‌جایی با دو انگشت؛ دو بار لمس سریع هم زوم می‌کند. در زوم بالا، متن همچنان واضح رسم می‌شود
- نوار ابزار پایین (مثل OneDrive):
  - **دست**: اسکرول و پرتاب صفحه با یک انگشت
  - **هایلایت**: با یک انگشت روی متن بکشید؛ خط به‌صورت شبه‌شفاف رسم می‌شود. اگر تقریباً افقی بکشید، خودکار صاف و تمیز می‌شود
  - **قلم**: نوشتن/خط‌کشیدن آزاد با رنگ‌های مشکی، قرمز، آبی، سبز و نارنجی
  - **پاک‌کن**: انگشت را روی خط بکشید تا پاک شود
  - **برگشت**: برگرداندن آخرین خط
  - پنج رنگ و سه ضخامت (باریک/متوسط/ضخیم)؛ در حالت هایلایت یا قلم، با دو انگشت می‌توانید جابه‌جا و زوم کنید
- هایلایت‌ها برای هر فایل جدا ذخیره می‌شوند و با بستن برنامه یا فایل نمی‌روند
- فهرست صفحه‌های دارای هایلایت، رفتن به صفحه، یادآوری آخرین فایل و صفحه

## ساخت APK با GitHub
1. همه‌ی فایل‌های این پوشه را در یک مخزن (Repository) در GitHub آپلود کنید.
2. به تب **Actions** بروید؛ ساخت به‌صورت خودکار شروع می‌شود (یا Run workflow بزنید).
3. بعد از پایان، از بخش **Artifacts** فایل `PdfHighlighter-apk` را دانلود کنید و APK داخلش را روی گوشی نصب کنید.

## نکته‌ها
- نمایش PDF با ابزار خود اندروید (`PdfRenderer`) انجام می‌شود و هیچ کتابخانه‌ی خارجی ندارد.
- هایلایت مثل ماژیک روی صفحه کشیده می‌شود، نه انتخاب خودکار کلمه‌ها (ابزار نمایش اندروید متن PDF را در اختیار نمی‌گذارد).
