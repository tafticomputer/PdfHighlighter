# هایلایت PDF (اندروید ۵.۱ به بالا)

برنامه‌ای برای باز کردن PDF، هایلایت کردن مطلب و ذخیره‌ی خودکار هایلایت‌ها.

## امکانات
- باز کردن PDF از حافظه (انتخاب فایل) یا از هر برنامه‌ای که PDF را «باز کردن با…» می‌دهد
- هایلایت: دکمه‌ی مداد را بزنید و انگشت را روی متن بکشید
- ۵ رنگ (زرد، سبز، صورتی، آبی، نارنجی) از منوی ⋮
- پاک‌کن: روی هایلایت بزنید تا حذف شود / برگرداندن آخرین هایلایت / پاک کردن همه
- هایلایت‌ها برای هر فایل جداگانه ذخیره می‌شوند و با بستن و باز کردن برنامه می‌مانند
- فهرست هایلایت‌ها (صفحه‌ها) با پرش سریع، رفتن به صفحه، بزرگ‌نمایی تا ۲۵۰٪
- برنامه آخرین فایل و آخرین صفحه‌ی خوانده‌شده را یادش می‌ماند

## ساخت APK با GitHub
1. همه‌ی فایل‌های این پوشه را در یک مخزن (Repository) در GitHub آپلود کنید.
2. به تب **Actions** بروید؛ ساخت به‌صورت خودکار شروع می‌شود (یا Run workflow بزنید).
3. بعد از پایان، از بخش **Artifacts** فایل `PdfHighlighter-apk` را دانلود کنید و APK داخلش را روی گوشی نصب کنید.

## نکته‌ها
- نمایش PDF با ابزار خود اندروید (`PdfRenderer`) انجام می‌شود و هیچ کتابخانه‌ی خارجی ندارد.
- هایلایت به‌صورت مستطیل رنگی روی صفحه است (مثل ماژیک)، نه انتخاب خودکار کلمه‌ها.
